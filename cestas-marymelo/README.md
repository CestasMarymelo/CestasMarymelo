# Cestas Mary Melo

Landing page simples (HTML + CSS, sem dependências).

## Estrutura
```
index.html        página principal
css/style.css     cores, fontes e layout (cores no topo, em :root)
assets/img/       imagens da página
```

## Trocar os ícones pelas fotos
1. Coloque a foto em `assets/img/` (ex.: `hero.jpg`).
2. No `index.html`, troque o `src` da imagem correspondente (ex.: `assets/img/hero.svg` -> `assets/img/hero.jpg`).

| Local da página | Arquivo atual |
|---|---|
| Foto principal | `hero.svg` |
| Café da manhã | `cafe-da-manha.svg` |
| Tábuas de frios | `tabua-de-frios.svg` |
| Aniversários | `aniversarios.svg` |
| Maternidade | `maternidade.svg` |
| Datas especiais | `datas-especiais.svg` |
| Galeria | `galeria-1.svg` a `galeria-4.svg` |

Dica: use fotos em .jpg ou .webp com até ~300 KB cada para a página carregar rápido.

## Publicar no GitHub Pages
1. Suba todos os arquivos na raiz do repositório.
2. No GitHub: Settings > Pages > Source: "Deploy from a branch" > branch `main` / pasta `/ (root)`.
3. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
